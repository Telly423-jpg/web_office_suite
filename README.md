# web_office_suite
功能齐全的单文件离线 Web Office 套件（WPS/Canva 风格），并配有简体中文界面文本。
📄 文字文档（DOC）：Google Docs 风格的富文本编辑器，具有完整的格式选项。
🖼️ 图片编辑器（Image Editor）：基于 HTML5 Canvas 的图像编辑器，支持图像上传
💾 全局多格式导出与导入：本地存储自动保存以及（.json完整备份）、、、、和（图像捕获/导出）的导出选项。 .html .txt .csv.png
